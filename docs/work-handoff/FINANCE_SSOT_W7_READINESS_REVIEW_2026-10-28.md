The candidate has a generic reviewed shadow-import API and inventory scripts, but no complete per-revision LINE/OS transform or native/Card historical migration runner. Build exact booking and cross-source aliases/ownership for every accepted historical event. 4. Deploy additive schema/API behind closed flags, prove source-specific grants and per-property cutovers in an isolated environment, and exercise LINE group, private-message and LIFF plus OS and Sheet flows end to end. Then repeat final-delta reconciliation under an agreed Sweetfun pause window. Do not alter Offland's finance writer or projection while Sweetfun changes.
5. Observe a complete post-cutover operating cycle, including a real Sweetfun weekly Card confirmation if one occurs. A synthetic Card test does not establish that live Card reconciliation succeeded.
