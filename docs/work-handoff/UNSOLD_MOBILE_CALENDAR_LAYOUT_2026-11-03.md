# 未售月曆手機版高度與月初定位（2026-11-03）

使用者截圖顯示 2026 年 11 月只看見 11/2–11/8 一週，月曆框下方留有大面積空白。未售月曆有獨立的垂直捲動區；原先用 `visualViewport.height` 減去框的位置設定高度，在手機瀏覽器可縮到最低 280px。初始定位又使用 11/3 而非 11/1，將第一週捲出框外。

此候選修正改以 `window.innerHeight` 計算剩餘頁面高度，最低 320px，並讓月份模式從當月標題開始。日期選取、房晚資料與月曆內部捲動方式不變。

本機驗證：TypeScript、前端 ESLint（0 錯誤、7 個既有警告）、17 個月份版面測試及 Webpack 正式建置通過。Chrome 手機尺寸 390×844、440×956 與 WebKit 390×844 的未售框均延伸至視窗下緣約 12px；月份標題和 11/1 第一週可見，向下捲動可看後續週。將 `visualViewport.height` 人為縮為 600px 後，框高維持不變。這是本機示範資料的版面驗證，尚未發布，也未在使用者實機核對。
