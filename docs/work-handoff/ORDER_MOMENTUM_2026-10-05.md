## 計算口徑

1. 接單動能按實際下訂日期；以報告快照日為時間錨點。近 7 天排除尚未完整的當日。未知下訂日不補猜、不計入近期接單，但仍保留住宿月份與晚數。
2. 同一穩定訂單 ID 的合法拆列合併計數。無 ID 的完整包棟組／明確整單多房列可計數；無 ID 的散客逐房列或逐晚列不直接當成訂單。涉及無法識別的列時，完整總筆數顯示「至少 N 筆」，趨勢改以住宿單位晚數呈現。
3. 匿名 cohorts 保存合法住宿範圍、每段單位數、金額、下訂日、通路、來源列；不保存原始訂單 ID 或客人個資。逐段晚數用於跨月累積，不以整筆平均比例分配不同房數的住宿段。
4. 每晚均價採正金額房費與對應單位晚數。每筆平均房費只採可確認完整住宿與金額的訂單；逐晚來源不推估整筆客單價或真正入住日。
5. 住宿月份的跨月訂單每月各計一次，金額按原每日分析分攤；月份訂單數不可直接相加。下訂月份則將整筆現有住宿與已知房費歸於下訂月。
6. 同比累積圖從目前有效訂單按下訂日回推。它不是歷史快照或 Net Pickup，無法恢復取消、改期及已刪除訂單；未來里程碑不假造本期數字，資料／下訂日不足不下超前落後結論。
7. 通路提醒是固定規則：前期有而近期未見接單、接單下降至少 20%（前期至少 3 筆）、均價下降至少 10%（兩期至少 3 個有價晚數）、單一通路晚數占比至少 60%（近期至少 5 筆）。不代表因果或淨利判斷。
8. 速度常態須下訂日覆蓋完整且前 4 週至少 3 週有紀錄；少量訂單採保守提示。資料來源完整性、可售庫存、季節差異仍需另外確認。
9. 金額為已知房費，未扣佣金／稅費／成本；缺值顯示 —，零紀錄不聲稱為完整需求或完整可售狀況。
