# OwlNest 控房 API 查核

日期：2026-10-13（Asia/Taipei）

OwlNest 的[官方產品頁](https://www.owlting.com/owlnest/?l=tw)介紹 OTA 串接與自動控房，並提供客服聯絡方式。[官方操作教學](https://static.owlting.com/owlnest/documents/OwlNest%E7%B3%BB%E7%B5%B1%E6%93%8D%E4%BD%9C%E6%95%99%E5%AD%B8_20190327.pdf)說明如何在後台手動更改房型開關與庫存。查核公開資料後，**未找到可供第三方實作的正式開／關房寫入 API 規格**。這不證明 OwlNest 沒有提供私有合作夥伴 API。

目前 OS 程式只有 `frontend/src/lib/owlnest-refresh.ts` 的讀取房況連線；不能用讀取端點或後台畫面推定寫入路徑、權限或重試語意。另一個定價系統的價格寫入經驗也不等於房量／鎖房 API 授權。

Iron Gate 因此保留注入式的合成通路執行器，真實 OwlNest 寫入保持關閉。正式接線至少需要供應商確認：

1. 可用的合作夥伴寫入規格、認證方式、帳號與館別範圍；
2. 房型／實體房映射，以及逐晚設定庫存數與鎖房的精確語意；
3. 請求防重、未知結果重查、速率限制及開房／關房失敗後的恢復規則；
4. 可隔離的測試館與測試憑證，並允許逐晚讀回驗證。

在這些資料與授權到位前，`saleReady=false`；不能依網站顯示的本地空房直接對外接單，也不能以未記錄的後台請求模擬官方接口。
